नामको राशि खोज्नुहोस् (Rashi Finder)

बच्चीको नाम राख्दा धेरै परिवारले राशिको नामाक्षर हेर्छन्। यहाँ नाम लेख्नुहोस्, पहिलो अक्षरले कुन राशिमा पर्छ भनेर तुरुन्तै देख्नुहोस्।

Many Nepali families check the rashi letter before choosing a baby's name. Type a name below and see which rashi its first letter falls under.

कसरी प्रयोग गर्ने? / How to use

  1. नाम देवनागरीमा लेख्नुहोस् (जस्तै: रिया)।
    Type the name in Devanagari.
  2. “खोज्नुहोस्” थिच्नुहोस्।
    Press the search button.
  3. तल तालिकामा सम्बन्धित राशि छुट्टिएर देखिन्छ।
    The matching rashi is highlighted in the table below.

यो साधनले नामको पहिलो अक्षर मात्र हेर्छ। जन्मराशि चाहिँ जन्म मिति, समय र ठाउँअनुसार ज्योतिषीले निकाल्छन्।

This tool only looks at the first letter of the name. The birth rashi itself is worked out by an astrologer from the birth date, time and place.
